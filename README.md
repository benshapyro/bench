# Bench

Helps a business buyer pick an AI model for a job: the best one, the cheapest one that's good enough, and what each costs per month. Will live at bench.shapyro.com.

| Folder | What's in it |
|---|---|
| `docs/` | The spec (`BENCH-SPEC.md`), the Phase 0 data-check report |
| `data/` | Scores, models, prices, benchmarks and jobs, with sources (`data/README.md`) |
| `usage-run/` | The script that measures how many tokens each model uses (`usage-run/README.md`) |
| `prototypes/` | Home page design prototypes |

API keys go in environment variables, never in this repo.
